# 수담 — 한국 장기

`janggi-dev-prompts.md`의 **P0~P9 및 P12**를 구현한 로컬 2인 장기게임입니다. **P10 AI와 P11 온라인 대전은 구현하지 않았습니다.** 다른 프로젝트 폴더와 독립적으로 실행됩니다.

## 실행

Node.js 22.12 이상을 권장합니다. Node 25.9에서 검증했습니다.

```bash
cd codex-astra
npm ci
npm run dev
```

터미널에 표시되는 로컬 주소를 브라우저에서 엽니다. 양쪽 진영의 마상 배치를 고른 후 **대국 시작하기**를 누르세요.

```bash
npm test                 # Vitest 규칙·기보·상태 테스트
npm run validate:random  # 시드가 고정된 1,000판 검증
npm run build            # TypeScript 검사 + 정적 배포 파일 + 오프라인 캐시
npm run preview          # 실제 프로덕션 빌드 미리보기
```

## 기능

- 초·한 각각 마상 배치 4종과 장기판 미리보기
- 9×10 SVG 교차점 보드, 궁성 대각선, 한국 장기의 7종 기물 이동
- 포대·마/상 길막힘·장군·외통·빅장·반복·기물 점수 판정
- 클릭, 마우스/터치 드래그, 방향키 + Enter/Space, Escape 선택 취소
- 합법수와 잡을 수 있는 기물 표시, 마지막 수와 장군 강조
- 한 수 쉬기, 무르기, 기권, 상대방 수락을 거치는 합의 점수 판정
- 경과 시간, 양측 점수, 잡힌 기물, 한글 기보
- JSON 내보내기/불러오기, 처음·이전·다음·마지막 복기 및 복기 중 착수 차단
- 자동 저장과 새로고침 후 복구 선택, 저장 실패 안내
- 보드 뒤집기, 한글 기물, 색 구분 팔레트, 색 외에도 진영을 구분하는 표시
- 모바일 대응, 44px 이상 조작 타깃, 키보드 포커스, 이동 감소 설정 존중
- 프로덕션 PWA: 설치 가능한 매니페스트/아이콘, 오프라인 로컬 대국
- 에러 바운더리와 저장 대국 복구

## 규칙의 기준

[원본 요구사항](../janggi-dev-prompts.md)의 P1 본문을 [RULES.md](RULES.md)에 그대로 저장했습니다. 별도의 외부 경기 규정으로 덮어쓰지 않았으며 샹치 규칙을 사용하지 않습니다.

- 기물의 기본 총점은 양측 72점이며, 한에 덤 1.5점을 더해 **초 72 / 한 73.5**로 시작합니다.
- 빅장 설정이 켜졌을 때 양 궁이 방해물 없이 마주보면 즉시 점수 판정합니다. 끄면 빅장으로 종료하지 않습니다.
- 무승부 조건과 합의 비김도 문서에 따라 **남은 기물 점수가 높은 쪽의 승리**로 처리합니다.
- 반복은 기물 종류·진영·좌표와 다음 차례가 같은 국면을 셉니다. 기물 ID는 제외하며 pass도 국면 기록에 포함합니다. 기본 3회, 화면에서 3~5회, 엔진에서 2~10회를 지원합니다.
- 외통은 궁을 잡기 전에 끝납니다. 장군 중 pass와 자기 궁을 노출하는 수는 금지합니다.
- 일반 대국에는 수 제한이나 스테일메이트 패배가 없습니다.
- 경과 시간은 라이브 대국에서 흐르며 복기 중에는 멈춥니다. 서버 대국 시계/시간패는 P11 범위입니다.

## 구조

```text
src/engine/       순수 TypeScript 규칙·불변 상태·좌표·승패 판정
  moves/          기물별 의사이동 생성기
  janggi-notation.ts  사람이 읽는 기보 표기를 한곳에서 정의
src/game/         useReducer + Context, 엄격한 JSON 검증과 엔진 기반 재생
src/ui/           props 기반 SVG 보드, 화면·입력·저장·접근성
scripts/          랜덤 검증, 폰트 선택, 오프라인 서비스워커 생성
public/           PWA 매니페스트와 아이콘
```

엔진은 React, DOM, 브라우저 저장소를 참조하지 않습니다. `createGame`, `generateLegalMoves`, `makeMove`, `pass`, `undo`, `getGameResult`, `debugPrint` 등을 `src/engine/index.ts`에서 내보냅니다. AI/온라인 모듈을 나중에 같은 엔진에 연결할 수 있습니다.

기보에는 초기 배치·설정·수·종료 결과를 저장합니다. 불러올 때 모든 수를 엔진으로 다시 실행하고 기물·잡힌 기물·차례·종료 결과까지 대조합니다. 임의의 보드 상태나 결과를 그대로 신뢰하지 않습니다. 파일은 2MiB, 2,000수, 경과 시간은 365일까지 지원하며 초과 시 오류를 안내합니다.

## 검증

- Vitest **65개** 통과: 기물별 경로, 합법수, 장군/외통, 빅장, 반복, 점수, 불변 상태, 무르기, JSON 검증, 기보, 복기, reducer, 서비스워커 오프라인 캐시.
- 기본 배치 perft 기준값: **depth 1 = 31, depth 2 = 961, depth 3 = 30,142**. pass는 제외하며 이 구현의 회귀 기준값입니다. 외부에서 인증된 장기 표준 수치라고 주장하지 않습니다.
- 브라우저에서 클릭·드래그 잡기·키보드 착수·쉬기·무르기·복기 차단·기권·자동 복구를 확인했습니다. 390px 화면에서 가로 넘침 없이 44px 터치 영역을 확인했으며, 서버를 종료한 상태에서 오프라인 새로고침·복구·착수도 통과했습니다.
- 고정 시드 **1,000판, 131,580수, 생성 후보 4,871,556개** 검사. 모든 실제 착수/pass 후 무르기가 이전 상태와 일치하는지 확인했습니다.
- 랜덤 검증은 실행을 유한하게 끝내기 위해 160수에서 진행 중인 판을 합의 점수로 종료합니다. 빅장 280판, 외통 50판, 반복 1판, 검증용 제한 후 합의 669판입니다. **이 제한은 게임에 적용되지 않습니다.**

## 배포·오프라인

`npm run build`가 만드는 `dist/`를 정적 웹 서버에 올립니다. `base: './'`를 사용해 하위 디렉터리에서도 호스팅할 수 있습니다. 서버에서 HTTPS를 사용해야 하며 localhost는 개발 예외입니다. `index.html`과 `sw.js`는 장기 캐시하지 않고, 해시가 붙은 assets에는 긴 캐시를 적용할 수 있습니다.

서비스워커는 프로덕션 빌드에서만 등록됩니다. 첫 온라인 접속 때 앱·기물/텍스트 폰트·아이콘을 캐시하고 이후 인터넷 없이 로컬 대국을 실행합니다. 개발 서버에는 오프라인 캐시를 등록하지 않습니다. 브라우저 데이터를 지우면 자동 저장과 오프라인 캐시도 지워질 수 있으므로 보관할 대국은 JSON으로 내보내세요.

Noto Sans/Serif KR 글꼴은 설치된 `@fontsource` 패키지에서 자체 호스팅합니다. dev/build 전 Node 스크립트가 소스의 문자에 필요한 WOFF2 조각만 골라 전체 폰트를 약 90% 줄입니다. UI 문구 추가 시 다음 dev/build에서 자동 재생성됩니다. 글꼴·아이콘 등의 라이선스는 `public/THIRD_PARTY_NOTICES.txt`에 함께 제공합니다. Lucide 아이콘은 `lucide-react`를 사용합니다.
