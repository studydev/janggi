# 웹 장기 프로젝트 헌법

웹 기반 장기(Korean Chess, Janggi) 게임을 만든다. 아래 내용을 프로젝트 전체 규칙으로 삼는다.

## 기술 스택

- TypeScript(strict), React 18, Vite
- 상태관리: 외부 라이브러리 없이 useReducer + Context
- 보드 렌더링: SVG
- 테스트: Vitest

## 아키텍처 원칙

- `src/engine/`는 순수 함수만 둔다. React, DOM, 브라우저 API를 참조하지 않는다.
- `src/ui/`는 렌더링과 입력 처리를 담당한다. 규칙 판단은 엔진에 위임한다.
- 엔진 상태는 불변으로 다룬다. `makeMove`는 새 `GameState`를 반환한다.
- AI와 온라인 대전은 이번 구현 범위에 포함하지 않는다.

## 작업 방식

- 규칙 로직은 구현 전에 테스트 케이스를 먼저 작성한다.
- 규칙이 애매하면 다른 체스류 게임의 상식으로 추측하지 않고 `RULES.md`를 우선한다.
- 한 번에 하나의 규칙 모듈을 구현하고 관련 없는 파일은 건드리지 않는다.

## 금지

- 장기를 중국 샹치 규칙으로 구현하지 않는다. 강(河)은 없고, 상은 1직진+2대각이며, 포는 이동할 때도 반드시 하나를 넘는다.
