# 장기 규칙 명세

## 보드

- 9열 × 10행. 기물은 칸이 아니라 선의 교차점에 놓인다.
- 좌표: file 1~9 (왼쪽→오른쪽), rank 1~10 (위→아래).
- 궁성(宮): 한(漢) = file 4~6 / rank 1~3, 초(楚) = file 4~6 / rank 8~10.
  각 궁성에는 네 귀퉁이와 중앙을 잇는 대각선이 그어져 있다.
- 강(河)은 존재하지 않는다.

## 초기 배치

- 한(漢)이 위쪽(rank 1~4), 초(楚)가 아래쪽(rank 7~10)에 놓인다.
- 한: rank1 = 차(1) 마/상(2) 마/상(3) 사(4) 빈(5) 사(6) 마/상(7) 마/상(8) 차(9)
      rank2 = 궁(5) / rank3 = 포(2), 포(8) / rank4 = 병(1,3,5,7,9)
- 초: 위 배치를 상하 대칭. rank10 = 차·사·차, rank9 = 궁(5), rank8 = 포(2,8), rank7 = 졸(1,3,5,7,9)
- 마·상 배치는 대국 시작 전 각자 고른다: 마상마상 / 상마상마 / 마상상마 / 상마마상
- 초(楚)가 선수(먼저 둔다).

## 기물별 이동

- 궁(將): 궁성 안에서만 선을 따라 1칸. 궁성 대각선 위에서는 대각으로도 1칸.
- 사(士): 궁과 동일. 궁성을 벗어날 수 없다.
- 차(車): 가로·세로로 막힐 때까지 직진. 궁성 안 대각선 위에 있으면 그 대각선을 따라 직진 가능.
- 포(包): 이동과 공격 모두, 사이에 정확히 기물 1개(포대)를 넘어야 한다.
  - 포대가 0개거나 2개 이상이면 그 방향으로 갈 수 없다.
  - 포는 다른 포를 넘을 수 없다. 포는 다른 포를 잡을 수 없다.
  - 궁성 대각선에서도 같은 조건(궁성 중앙에 포대가 있으면)으로 이동 가능.
- 마(馬): 직선 1칸 + 대각 1칸. 첫 직선 칸에 기물이 있으면 막혀서 못 간다(다리 막힘).
- 상(象): 직선 1칸 + 대각 2칸. 경로상 중간 두 지점 중 하나라도 막히면 못 간다.
- 졸/병(卒/兵): 앞 또는 좌우로 1칸. 뒤로 갈 수 없다.
  - 상대 궁성 안의 대각선 위에서는 대각으로 전진할 수 있다.

## 대국 진행

- 한 수 쉬기(pass) 허용. 스테일메이트는 존재하지 않는다.
- 장군(check)을 받으면 반드시 멍군(해소)해야 한다. 해소 불가 = 외통 = 패배.
- 자기 궁이 장군에 노출되는 수는 둘 수 없다.
- 빅장(양 궁이 같은 줄에서 사이에 기물 없이 마주봄): 기본은 비김. 설정으로 on/off.
- 같은 국면이 반복되면 비김 처리(반복 횟수는 설정값).

## 점수

- 차 13, 포 7, 마 5, 상 3, 사 3, 졸/병 2, 궁 0.
- 한 진영은 후수 보상으로 1.5점(덤)을 받는다. 초기 총점은 각 72점이다.
- 무승부 조건 발생 시 점수가 높은 쪽이 승리한다.
