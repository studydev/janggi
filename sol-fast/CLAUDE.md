# 웹 장기 프로젝트 헌법

웹 기반 장기(Korean Chess, Janggi) 게임을 만든다. 아래를 프로젝트 전체 규칙으로 삼는다.

## 기술 스택

- TypeScript(strict), React 18, Vite
- 상태관리: 외부 라이브러리 없이 useReducer + Context
- 보드 렌더링: SVG
- 테스트: Vitest

## 아키텍처 원칙

- `src/engine/`: 순수 함수만 둔다. React, DOM, 브라우저 API를 참조하지 않는다. 이 폴더만으로 콘솔 대국이 가능해야 한다.
- `src/ui/`: 렌더링과 입력만 처리하고 규칙 판단 로직을 두지 않는다.
- 엔진 상태는 불변으로 다룬다. `makeMove`는 항상 새 `GameState`를 반환한다.

## 작업 방식

- 한 번에 하나의 모듈을 구현한다.
- 규칙 로직은 테스트와 함께 구현한다.
- 규칙이 애매하면 추측하지 않는다.
- 모든 규칙 판단은 `RULES.md`를 최우선 근거로 한다.

## 금지

- 장기를 중국 샹치 규칙으로 구현하지 않는다.
- 강(河)은 없고, 상은 1칸 직진 후 2칸 대각선으로 이동한다.
- 포는 이동과 공격 모두 반드시 기물 하나를 넘는다.
