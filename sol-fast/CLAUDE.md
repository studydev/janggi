# 웹 장기 프로젝트 헌법

## 기술 스택
- TypeScript strict, React 18, Vite
- 상태 관리는 외부 라이브러리 없이 `useReducer`와 Context를 사용한다.
- 보드는 SVG로 렌더링한다.
- 테스트는 Vitest를 사용한다.

## 아키텍처 원칙
- `src/engine/`은 순수 함수만 포함하며 React, DOM, 브라우저 API를 참조하지 않는다.
- `src/ui/`는 렌더링과 입력만 담당하고 규칙 판단은 엔진에 위임한다.
- 엔진 상태는 불변으로 다루며 착수 함수는 새 `GameState`를 반환한다.
- 규칙 판단은 항상 `RULES.md`를 최우선 근거로 삼는다.

## 규칙 안전장치
- 이 게임은 중국 샹치가 아니라 한국 장기다.
- 강은 없고, 상은 직선 1칸 뒤 대각선 2칸을 간다.
- 포는 이동과 공격 모두 포대 하나를 반드시 넘어야 한다.
- 포는 포를 넘거나 잡지 못한다.
- 졸과 병은 처음부터 옆으로 움직일 수 있다.
- 한 수 쉬기를 허용한다.
